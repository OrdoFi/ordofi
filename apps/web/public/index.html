Built for a sequencer chain

Robinhood Chain has no public mempool and orders transactions first-come-first-served. MEV here is a latency race, not a fee auction. OrdoFi is built for exactly that.

🛡️

Revert protection

Every transaction is simulated from the recovered sender before it reaches the sequencer. Guaranteed reverts never burn gas.

🔗

Best-effort bundles

How the auction works

A MEV-Share-style order-flow auction adapted for a single-sequencer chain.

1

Submit

A wallet or app sends a user transaction to the OrdoFi gateway instead of the raw sequencer.

2

Auction

A redacted hint is broadcast to searchers, who bid sealed for the right to backrun it.

3

Dispatch

The user tx and the winning backrun fire back-to-back from colocated infra. The user tx is never delayed.

4

Rebate

The winning bid is split between the user, the app, and the protocol, attributed automatically.
